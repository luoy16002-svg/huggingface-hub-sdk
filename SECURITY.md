# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/luoy16002-svg/huggingface-hub-sdk/issues.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/luoy16002-svg/huggingface-hub-sdk/issues

## Scope

This policy applies to the generated Kai Chen SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Hugging Face Hub public API, generated by
Kai Chen. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
